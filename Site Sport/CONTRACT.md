## UX requirements
Persisted onboarding overlay root. Default history empty, dashboard nice empty charts. No demo seeded workouts. Honest browser-only notifications app open; calendar ICS export root. Use all required program exercises (no auto replacements). Nutrition whey logging must avoid double count: centralized mark-whey event handled in Supplements component or helper root toggleSupplement(key,date) available in context, creates/removes single meal source:'whey' iff trackProtein. Root context toggleSupplement available all pages. Profile measurement form in onboarding and settings. Components accessible, button type default button, all dialogs role dialog and form submit. Do not change other agents' files. Keep changes via apply_patch.
